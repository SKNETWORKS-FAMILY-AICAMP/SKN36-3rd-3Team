## 확인할 내용

- [ ] 고령층 관련 정책의 대상·지원 내용·신청 방법·문의처를 확보할 수 있는가?
- [ ] 정책 원문으로 연결되는 공식 URL이 있는가?
- [ ] 종료된 정책, 지역 제한, 변경 이력을 구분할 수 있는가?
- [ ] API 인증이나 활용 신청이 필요한가? 실제 응답을 확인했는가?
- [ ] 저장·재사용 및 서비스 활용 조건을 확인했는가?

API가 없으면 '없음', 확인하지 못했으면 '미확인'으로 구분합니다. 인증키는 기록하지 않습니다. 샘플 응답은 개인정보와 인증정보를 제거하고 공유합니다.
