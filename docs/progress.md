## 실행 및 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_data_pipeline.py -v
```

- Python 3.11.15 / pypdf 6.21.4.
- 오프라인 테스트 17개 통과(0.153초). HTTP pagination·timeout·반복페이지·실패응답·키비노출, 스키마, 멱등성, 분할, null, PDF 지역 비추정, 합성 제외, 빈페이지 기록 검증.
- 실제 입력: XML 199개, PDF 5개, API목록 JSON(461건). 목록은 상세 XML의 공식링크를 연결하는 데 사용.
- 실제 출력: **2,714청크 / 원본 51건(정책46+PDF5)**.
- 중앙 API 91청크, PDF 2,623청크.
- 건너뜀 154파일: 노년·노인 휴리스틱에 맞지 않은 XML153 + 별도 본문을 생성하지 않는 API목록JSON1. 전 연령 정책 중 고령층에 필요한 정보가 빠질 수 있어 데이터 담당 검토 필요.
- 추출텍스트가 없는 PDF 페이지 50개(파일별 2/13/8/4/23). 표지·빈면·스캔본을 구분하지 않으며 OCR 필요 여부는 미검증. 상세 페이지 번호는 로컬 report.json에 있음.

## 미확인 값과 남은 한계

- 지역·min_age·collected_at·신청기간·좌표·주소는 이 입력에서 전부 null. 원문에 없는 값을 생성하지 않았다.
- API 91청크는 기관·연도·전화·공식URL 보존. PDF는 manifest 미입력으로 해당 필드가 null이며 전체 출력 기준 null 비율 약96.65%.
- 표·스캔 OCR·PDF 간 중복 정책 연결, 129 실제 FAQ 확보, 시설·지자체 API 실제 호출/필드매핑, 이용조건·최신성 확인은 데이터 담당 후속 작업.
- DB·지역·모델의 팀 확정은 별도. 경남 포털 자료라는 이유로 정책 적용지역을 경남으로 고정하지 않음.
- 원본·출력 JSONL·전체 report.json·실행 로그·키는 커밋하지 않음. 이전에 팀원이 추적한 원본 파일도 삭제하지 않음.
