# 이전 기수 유사 프로젝트 조사

상태: 조사 대기. 프로젝트의 실제 README·문서·코드를 확인하여 작성합니다.

## 프로젝트별 조사 양식

- 프로젝트명 / 기수 / 팀:
- 저장소 링크:
- 확인한 문서·코드 링크:
- 해결하려는 문제 및 대상 사용자:
- 사용 데이터 및 확보 방법:
- RAG 구조: 문서 분할 / 임베딩 / 검색 / 답변 생성
- 기술 스택:
- 평가 방식 및 확인 가능한 결과:
- 고령층 정책 챗봇에 참고할 점:
- 그대로 적용하기 어려운 점:
- 코드·데이터 라이선스:
- 확인일 / 조사자:

확인되지 않은 부분은 '미확인'으로 표시하고, 참고와 복제를 구분합니다.
