# 노인복지 챗봇 활용 데이터

## 1. 노인복지시설 좌표 데이터

- **링크:** [공공데이터포털 — 노인복지시설 좌표 데이터](https://www.data.go.kr/data/15056929/openapi.do)
- **활용 방법:** RAG 문서에 근처 노인복지시설 관련 정보를 추가하여, 어르신들에게 주변 노인복지시설을 안내합니다.

## 2. 한국사회보장정보원_지자체복지서비스

- **링크:** [공공데이터포털 — 한국사회보장정보원_지자체복지서비스](https://www.data.go.kr/tcs/dss/selectApiDataDetailView.do?publicDataPk=15108347)
- **활용 방법:** 노령인구에 한정되지 않은 복지서비스 정보를 지자체 단위로 불러와, 지역별 복지서비스 안내에 활용합니다.
