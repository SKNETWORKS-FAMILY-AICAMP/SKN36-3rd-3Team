# 고령층 복지정책 챗봇 데이터 출처 조사

> 조사 목적: 고령층 복지정책 RAG 챗봇의 **답변용 지식 데이터**와 **평가용 질문 데이터** 확보

## 1. 2026년 노인보건복지 사업안내

- **출처:** 보건복지부 / [디지털집현전 — 2026년 노인보건복지 사업안내 ①](https://k-knowledge.kr/srch/read.jsp?id=282187073)
- **담고 있는 내용:** 노인일자리, 경로당·노인복지관, 맞춤돌봄, 응급안전안심서비스, 무료급식, 치매·건강 지원, 노인요양·장기요양 등 노인복지 사업 전반. 사업별 운영 지침과 대상·기준에 관한 내용도 포함됨.
- **데이터 형태:** 정책 **보고서·사업안내서**로, 권별·장별(일반현황, 사회활동, 돌봄, 건강, 요양 등)로 구분된 서술형 자료. 링크는 문서 소개 페이지이며, 원문 파일의 수집 방법과 이용 조건은 별도 확인이 필요함.
- **챗봇 활용:** 서비스별 지원 대상과 내용, 신청 관련 안내를 검색하는 **RAG 지식 문서**로 활용. 사업명·분야·시행연도 등을 메타데이터로 붙여 검색하고, 이용자에게 필요 없는 기관 운영·행정 지침은 분리하여 제공.

## 2. 2026년 기초연금 사업안내

- **출처:** 경상남도 복지포털 / [2026년 기초연금 사업안내](https://welfare.gyeongnam.go.kr/index.gsnd?cmd=view&menuId=0000000024&post=84)
- **담고 있는 내용:** 기초연금 신청 대상과 방법, 소득·재산 조사 및 수급자 선정 기준, 연금액 산정·지급 절차, 이의신청과 수급자 사후관리 등.
- **데이터 형태:** 복지자료실 게시물에 첨부된 **PDF 지침서**. 제도 설명과 세부 기준이 문단·항목 단위로 정리된 비정형 문서 형태.
- **챗봇 활용:** “기초연금을 신청할 수 있나요?”, “소득과 재산은 어떻게 계산하나요?” 등 **기초연금 관련 질문의 근거 문서**로 사용. 신청 자격·산정 기준·절차를 항목별로 나눠 검색하고, 연도별 기준 변경 여부를 함께 확인. 개인의 실제 수급 여부는 챗봇이 단정하지 않도록 처리.

## 3. 2026 나에게 힘이 되는 복지서비스 가이드북

- **출처:** 사회보장위원회 / [복지서비스 가이드북](https://www.ssc.go.kr/home/kor/contents.do?menuPos=50)
- **담고 있는 내용:** 약 **480개 복지서비스**를 폭넓게 소개. 노후 소득지원, 노인 일자리, 보건의료, 노인 돌봄 등 고령층 관련 서비스와 그 밖의 생애주기별 지원 정책 포함.
- **데이터 형태:** **e-book·PDF 안내책자**. 종합 안내서와 ‘노령층 지원’ 등 대상·상황별 자료로 나뉘며, 일부 정책 내용이 여러 책자에 중복될 수 있음.
- **챗봇 활용:** 사용자의 상황에 맞는 **지원 제도 탐색 및 추천 후보 검색**에 활용. 관련 제도명을 먼저 찾은 뒤 자세한 지원 기준은 사업안내서 등 원문과 대조. 중복 항목은 정책명·시행연도 등을 기준으로 정리.

## 4. 보건복지상담센터(129) 노인·장애인 자주하는 질문

- **출처:** 보건복지상담센터 / [자주하는 질문 — 노인장애인](https://www.129.go.kr/faq/faq05.do)
- **담고 있는 내용:** 노인장기요양제도, 복지 지원, 장애인 관련 제도 등에 대한 **질문과 답변**. 노인 정책과 관계없는 장애인 전용 질문도 포함되어 있어 분류가 필요함.
- **데이터 형태:** 웹페이지의 **FAQ 게시글**. 상담 분야, 질문 제목, 답변 본문, 작성일, 조회수 등의 정보로 구성됨. 별도 다운로드형 데이터셋이나 공식 API 제공 여부는 확인이 필요함.
- **챗봇 활용:** 노인 정책에 해당하는 질문을 선별해 **RAG 챗봇 평가용 질문·참고 답변**으로 활용. 답변 정확도와 관련 근거 검색 여부를 점검하고, 챗봇이 답할 수 없는 질문도 구분해 평가할 수 있음. 단, 게시된 FAQ가 실제 상담 빈도를 통계적으로 반영한 목록이라고 단정할 수는 없음.

## 활용 방향 요약

| 자료 | 주된 용도 | 전처리·확인 사항 |
|---|---|---|
| 노인보건복지 사업안내 | 노인복지 전반의 상세 정책 근거 | 장·사업별 문서 분할, 이용자 대상 정보 선별 |
| 기초연금 사업안내 | 기초연금 신청·선정·지급 안내 | 기준연도·조건·절차 메타데이터 관리 |
| 복지서비스 가이드북 | 상황별 복지서비스 탐색 | 정책 중복 제거, 상세 지침과 대조 |
| 129 자주하는 질문 | 실제 질문 형태 참고 및 챗봇 평가 | 노인 관련 질문 선별, 답변 최신성 확인 |

**공통 유의사항:** 복지제도는 시행연도와 지역에 따라 세부 조건이 달라질 수 있음. 실제 챗봇에서는 근거 문서의 발행연도·소관기관을 표시하고, 문서 다운로드·수집·재이용 가능 여부를 각 사이트의 이용 조건에 맞춰 확인해야 함.
