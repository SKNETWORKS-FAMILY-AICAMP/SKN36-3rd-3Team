|---|---|

### R-7. 통합시 시 단위 정책의 적용 지역 (73건)

R-1 표의 시 단위 광주 25 + 전남 22 + 불분명 24 + 교육청 2건에 아래 규칙을 적용합니다.

| 근거 | 처리 |
|---|---|
| 원문 문장·시점·담당 기관을 함께 보고 **옛 광주 지역 대상**이 분명함 (예: `(구)광주광역시에 주소를 둔`) | `applies_to` = 옛 광주 5개 구 목록, `scope_status=candidate`, `scope_basis`에 근거 문장 |
| 같은 방식으로 **옛 전남 지역 대상**이 분명함 (예: `전라남도에 주민등록을 두고`) | `applies_to` = 옛 전남 22개 시군 목록, `candidate`, 근거 문장 |
| 공고·조례로 **통합시 전체** 적용이 확인됨 | `region_scope=sido`, `applies_to=[{"sido": "전남광주통합특별시", "sigungu": null}]`, `confirmed` |
| 단서 없음, 또는 두 단서가 함께 있음 | `region_scope=unknown`, `applies_to=[]`, 미해결 목록 |
| 교육청 2건 | `sigungu_name=null` (원문은 `raw_sigungu_name`). 적용 범위는 본문 근거로만 (WLF00006509는 특정 학교군 대상) |

`도내`, `광주시 거주` 같은 **단어 하나만으로 자동 배정하지 않습니다.** 부서 이름(예: "여성가족국", "보건복지본부")만으로도 판단하지 않습니다. 통합 후 두 지역 부서 이름이 섞여 있습니다. 문맥이 불분명하면 `applies_to=[]`로 둡니다.
