# 정책 데이터 수정 요약 · 2026-11-25

## 한눈에 보기

팀의 [PR #36](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN36-3rd-3Team/pull/36)에서 **정책 원본 4,278건을 한 파일로 모아 두었습니다.** 이번 작업은 그 파일을 받아 **검색에 쓸 정책 후보를 만들고, 잘못된 정보가 들어가지 않도록 검사**하는 단계입니다. 현재 서비스의 DB나 검색 결과를 바꾸는 작업은 아닙니다.

| 무엇이 문제였나? | 어떻게 고쳤나? | 지금은? |
|---|---|---|
| 조회수를 문의 전화번호로 착각할 수 있었음 | API의 `inqNum`은 조회수이므로 문의처 칸에 넣지 않음 | 새 정책 문서 1,778건에서 잘못된 전화번호 **0건** |
| 새 지역 자료가 옛 검색 자료와 섞일 수 있었음 | PR #36의 통합 파일에서 **새 실행 폴더**에 검색 자료를 처음부터 다시 만듦 | 정책 후보 **1,778건**, A/B 분할 자료 **4,754/5,240개** |
| 일부 지역·`노년` 태그를 놓치거나 지역을 확정할 수 있었음 | 지역 후보는 남기고, 맞는지 불확실한 정보는 검토 대기로 표시 | 15개 지역 원본 4,278건 처리. 신청 가능 여부는 **사람이 확인** |
| 옛 자료가 새 자료와 함께 DB에 남을 수 있었음 | 서로 다른 정책·분할 자료를 무심코 합쳐 적재하는 동작을 차단 | DB·Qdrant·Neo4j **미변경** |

**일상 비유:** PR #36은 여러 지역에서 받은 **주소록을 한 권으로 합친 작업**입니다. 이번 작업은 그 주소록을 바탕으로 **어르신에게 관련 있을 만한 카드를 찾아 책갈피를 붙이는 작업**입니다. 책갈피는 추천 후보 표시일 뿐, 실제 지원 대상이라는 도장은 아닙니다. `inqNum`은 가게의 **방문자 수**라서 전화번호 칸에 적으면 안 됩니다.

## 확인한 결과와 아직 남은 것

- 새 후보 **1,778건**, 추가로 사람 검토가 필요한 자료 **1,487건**, 제외 후보 **1,013건**을 각각 보존했습니다. 검색 문서와 분할 자료의 ID 연결 검사를 통과했습니다.
- 100가지 조합을 포함한 **133개 자동 테스트가 통과**했습니다. 이 검사는 모든 정책의 실제 신청 자격을 보증하지 않습니다.
- PR #36의 검증 보고서는 원본 파일의 **Windows 줄바꿈**으로 해시를 계산했고, GitHub에는 **다른 줄바꿈**으로 저장됐습니다. 줄바꿈만 되돌렸을 때 해시가 정확히 맞는 경우만 허용하고, 새로 받은 파일의 해시도 별도로 남깁니다. 비유하면 같은 문서를 다른 줄 간격으로 인쇄한 경우만 통과시킵니다.
- [공식 API 설명](https://www.data.go.kr/data/15108347/openapi.do)에 `inqNum=조회수`라고 명시돼 있습니다. 광주·전남 독립 원본은 아직 없고, 옛 검색용 574건에만 있던 전남 149건은 PR #36에서 **따로 보존**했습니다. 그 149건을 원본 4,278건에 임의로 더하지 않았습니다.
- 신청방법 본문 581건, 신청방법명 873건, 시군구 650건은 원본에서 비어 있습니다. 없는 값은 짐작해 채우지 않았습니다.

## 다음 순서

1. 광주·전남 원본과 별도 보존한 149건을 확인하고, 변경 후보를 담당자가 원문과 대조합니다.
2. 검토가 끝난 새 버전만 DB와 검색 인덱스에 **함께** 반영합니다. 이전 버전을 되돌릴 방법도 먼저 준비합니다.
3. 화면에서 정책 상세·문의처·검토 상태가 실제 데이터와 맞는지 확인합니다.
