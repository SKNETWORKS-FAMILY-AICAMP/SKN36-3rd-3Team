# 평가 계획 초안

구현 후 팀이 질문과 정답 근거를 준비해 평가합니다. 현재 측정된 결과는 없습니다.

| 항목 | 확인 방법 |
| --- | --- |
| 검색 정확성 | 질문에 필요한 공식 정책 문서가 검색되는지 확인 |
| 근거 일치 | 지원 대상·금액·기한·신청 방법이 출처와 일치하는지 확인 |
| 쉬운 설명 | 짧은 문장과 단계별 안내로 이해할 수 있는지 확인 |
| 조건 확인 | 지역·연령 등이 부족하면 추가로 질문하는지 확인 |
| 정보 부족 대응 | 근거 없는 답변 대신 확인 필요를 안내하는지 확인 |
| 최신성 | 정책 기준일·종료 여부·공식 링크 확인 |

테스트 질문에는 정상 질문, 지역이 모호한 질문, 종료된 정책, 자료에 없는 질문을 포함합니다. 실제 개인정보 대신 가상의 사례를 사용합니다.
