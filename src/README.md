# 지자체 복지서비스 API 데이터 수집
## 프로젝트 목적
지역별 노인 복지 정책을 검색·안내하는 RAG 기반 챗봇을 위한 기초 데이터를 확보한다. 고령화 비율을 고려해 수집 지역을 확대할 계획이며, 현재 1차 대상은 전북특별자치도·서울특별시·경기도이다.
사용 데이터
- 출처: 공공데이터포털 — 한국사회보장정보원 지자체복지서비스 API
- 목록조회: 지역별 서비스 ID, 서비스명, 지역, 서비스 요약, 수정일 등
- 상세조회: 목록의 servId를 기반으로 지원대상, 선정기준, 지원내용, 신청방법 등 상세 정보 조회
- 응답 형식: XML → pandas.DataFrame 변환
## 구현 내용
1. .env의 인증키로 API 호출 (python-dotenv)
2. ctpvNm으로 전북·서울·경기 목록 조회 및 페이지네이션 처리
3. 각 servId를 이용한 상세조회 (callTp=D)
4. 목록·상세 데이터를 servId 기준으로 병합
5. 지역별/전체 DataFrame 생성, 중복·누락·상세조회 실패 여부 확인
6. CSV 및 JSONL로 저장; 상세조회 결과를 캐시해 재실행 시 중복 호출 방지
실행 방법
1. 지자체복지서비스_전북_서울_경기_목록_상세조회.ipynb와 같은 폴더에 .env를 준비한다.DATA_GO_KR_API_KEY=본인의_공공데이터포털_디코딩_인증키
2. 노트북의 셀을 순서대로 실행한다. (라이브러리: requests, pandas, python-dotenv)
3. 상세조회 1건 테스트가 성공한 뒤 전체 상세조회를 진행한다. 필요한 경우 DETAIL_LIMIT = 20으로 먼저 소량 테스트한다.
4. 수집 결과는 outputs/ 폴더에 저장된다.
주요 결과 변수
변수	내용
df_all	세 지역 통합 목록
df_detail	서비스별 상세조회 데이터
df_full	목록 + 상세정보 병합 데이터
df_jeonbuk_full, df_seoul_full, df_gyeonggi_full	지역별 최종 데이터


## 확인 사항 및 향후 계획
- 확인 완료: 전북특별자치도 목록조회 API 정상 응답 및 DataFrame 생성 (당시 조회 조건 기준 totalCount=396).
- 실행 후 검증 필요: 서울·경기 전체 수집, 상세조회 필드 및 성공률. 노트북을 작성했다고 수집이 완료된 것은 아니다.
- 다음 단계: 고령자 관련 정책 선별 → 지역·대상·신청조건 메타데이터 정리 → RAG 검색용 문서 생성 및 벡터 DB 적재.
- 유의: API 호출 한도·데이터 최신성·실제 수급 자격 확인 필요. .env는 Git에 올리지 않는다.


# VWorld 노인복지시설 데이터 수집

## 1. 개요
VWorld 2D Data API를 활용하여 **서울특별시, 경기도, 전북특별자치도, 전라남도**의 노인복지시설 데이터를 수집하고, 지역별 DataFrame 및 JSON 파일로 저장하는 데이터 수집 파이프라인입니다.

- **데이터 출처:** [VWorld 노인복지시설 API](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=mgprtfb)
- **서비스 ID:** `LT_P_MGPRTFB`
- **수집 지역:** 서울, 경기, 전북, 전남
- **저장 형식:** CSV, JSON, GeoJSON
- **사용 라이브러리:** `requests`, `pandas`, `shapely`

## 2. 데이터 수집 Flow

```text
1. API 환경 설정
   ↓
2. 광역시도 경계 데이터 조회
   ↓
3. 지역별 BBOX 생성
   ↓
4. 노인복지시설 API 호출 (Pagination)
   ↓
5. Polygon 기반 지역 필터링
   ↓
6. DataFrame 변환 및 중복 제거
   ↓
7. CSV / JSON / GeoJSON 저장
```

## 3. 주요 처리 과정

**① API 호출 및 전체 데이터 수집**
- `vworld_get_feature()`: VWorld API를 호출하여 한 페이지의 데이터 조회
- `fetch_all_features()`: 페이지를 반복 호출하여 전체 데이터 수집

**② 지역별 데이터 필터링**
- 광역시도 경계 API를 통해 서울·경기·전북·전남의 Polygon 확보
- Polygon의 BBOX를 활용하여 시설 데이터 조회
- 실제 행정구역 Polygon 내부에 위치한 시설만 추출
- BBOX 조회 시 다른 지역의 시설이 포함되는 문제 방지

**③ DataFrame 변환 및 전처리**
- GeoJSON의 `properties`를 DataFrame 컬럼으로 변환
- `geometry`에서 위도·경도 추출
- 지역명(`region`) 컬럼 추가
- 시설 ID 기반 중복 제거

**④ 데이터 저장**
- CSV: 데이터 확인 및 분석
- JSON: RAG 문서 생성 및 백엔드 연동
- GeoJSON: 지도 시각화 및 공간 분석
